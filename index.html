Old Google Icons for Workspace

Privacy Policy

Last updated: May 24, 2026

Overview

Old Google Icons for Workspace is a Chrome extension that restores classic 2020-style icons for supported Google Workspace apps, including Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Meet, Chat, Keep and Maps.

Data collection

This extension does not collect, store, sell, transmit or share personal data.

It does not use analytics, tracking scripts, advertising identifiers or external servers.

What the extension can access

The extension requests access to supported Google app pages only so it can replace visual elements such as favicons, app launcher icons and compatible app logos.

The extension does not read email content, calendar events, Drive files, documents, messages, contacts, account data or browsing history.

Local icon files

All replacement icons are loaded locally from the extension package. The extension does not download icon files from external servers while you browse.

Permissions

The extension uses browser permissions only to change supported icons on supported Google app pages and to keep the Google Calendar icon updated with the current local day.

Third-party services

This extension does not send data to third-party services.

Contact

For questions, issues or privacy-related requests, please use the GitHub repository issues page for this project. https://github.com/arturguasch/old-google-icons-for-workspace
