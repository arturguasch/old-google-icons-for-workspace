# Old Google Icons for Workspace

Restore classic 2020-style Google Workspace icons for Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Meet, Chat, Keep and Maps.

## Features

- Restores classic-style tab favicons.
- Replaces supported top-left app logos.
- Updates supported icons in the Google app launcher.
- Includes dynamic Google Calendar icons from day 1 to day 31.
- Works with light mode and dark mode.
- Uses local icons included in the extension package.

## Supported apps

- Gmail
- Google Calendar
- Google Drive
- Google Docs
- Google Sheets
- Google Slides
- Google Forms
- Google Meet
- Google Chat
- Google Keep
- Google Maps

## Local installation

1. Download and unzip the extension.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the folder that contains `manifest.json`.

## Privacy

This extension does not collect, store, sell, transmit or share personal data.

It does not read email content, calendar events, Drive files, documents, messages, contacts or account data.

All replacement icons are loaded locally from the extension package.
